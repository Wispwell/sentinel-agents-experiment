# Target system

The mock system the resident agents attack. A stage set, not a simulation —
it only needs to support the phases the director actually schedules.

Needs, roughly: a boundary to cross, an egress point, planted credentials,
two or three "hosts" to move between, and a tamperable log.

Without a target the residents only *talk about* phases and the sentinel is
classifying conversation topics rather than detecting an intrusion. The target
is what forces each objective to be enacted, and it supplies the second source
of ground truth.
